 Amazon Sales Analysis – Power BI Dashboard

 📊 Overview
This Power BI dashboard provides a detailed analysis of **Amazon sales data**, focusing on key metrics like revenue, profit, order quantity, and category performance. It helps visualize business trends and identify top-performing products and regions.

---

 🧩 Features
- Interactive filters for category, region, and time period  
- KPI cards for total sales, profit, and order volume  
- Monthly and yearly sales trend analysis  
- Category-wise and regional performance insights  
- Data-driven visualizations for better decision-making  

---

 🛠️ Tools Used
- **Power BI Desktop**  
- **Microsoft Excel / CSV (data source)**  
- **DAX** for calculated metrics and measures
